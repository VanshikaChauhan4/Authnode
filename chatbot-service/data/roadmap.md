# AuthNode roadmap (demo scope)

This portfolio build includes:
- React frontend with role-based flows (Institution, Student, Employer)
- Python FastAPI backend with SQLite storage
- SHA-256 fingerprints plus RSA institution signatures
- Local RAG chatbot (Ollama + Chroma + sentence-transformers)

Future enhancements (not in this demo):
- Deploy backend to a cloud host
- Wallet-based student identity
- Public ledger on a blockchain network
- PDF certificate upload and parsing

For now everything runs locally: frontend on port 5173, API on port 5000, chatbot on port 8000.
