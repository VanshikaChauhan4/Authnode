# About this assistant

This is the AuthNode Assistant — a support and onboarding chatbot built specifically
for the AuthNode certificate verification platform.

## What it can help with

- How certificates are issued, stored, and verified on AuthNode
- What a Certificate ID is and how to find or share one
- How the fingerprint and digital signature system works
- Guidance for students, institutions, and employers/verifiers using AuthNode
- Troubleshooting common verification issues
- Explaining why AuthNode is built the way it is

## What it does not do

It does not answer general-knowledge questions unrelated to AuthNode (for example,
questions about world events, other products, or unrelated coding help). It's scoped
specifically to the AuthNode platform and the concepts directly relevant to it (like
digital fingerprints and digital signatures, since those are how AuthNode verification
actually works).

## How it answers

The assistant retrieves relevant passages from AuthNode's own documentation before
answering, rather than relying purely on general knowledge. If the documentation
doesn't cover something, it says so directly instead of guessing.
